# Claude Design 프롬프트 (앱 화면 시안)

**Claude Design 은 이 저장소에 접근할 수 없다.** 그래서 이 프롬프트는 완전히 자립해야 한다.
파일 경로나 git 명령을 넣지 않는다.

산출물(HTML 내보내기)은 `design/` 에 넣는다. 전작 관습(`git show legacy/v0.2:design/v2/`)을 잇는다.
`design/` 은 **읽기 전용**이다. 개발은 그걸 픽셀 단위로 따르고, 임의로 "개선"하지 않는다.

시안이 나온 뒤 개발 쪽에서 할 일:
1. `design/` HTML 에서 색·간격·타이포를 추출해 `Madi/UI/Tokens.swift`
2. 모든 문구를 `Madi/UI/Copy.swift` 한 파일로 (하드코딩 금지)

색 토큰 출발점은 전작에서 가져왔다 — `git show legacy/v0.2:CLAUDE.md` 의 디자인 토큰 절.

---

macOS 네이티브 앱 화면을 디자인해줘. SwiftUI 로 구현할 거야.

== 제품 ==

이름: 마디 (madi)
운동·재활 숏폼 크리에이터 한 명을 위한 AI 영상 편집 앱.

사용자는 물리치료사이고 인스타 릴스 12.5만 팔로워, 유튜브 4만이야.
"체형교정", "거북목 스트레칭" 같은 15~30초 숏폼을 계속 올려.
편집 지식이 없고, 타임라인을 못 읽고, 터미널을 몰라.
아이폰으로 찍으면 iCloud 사진으로 Mac 에 들어오고, 앱을 열면 영상이 이미 거기 있어.
말로 요청하면 편집된 결과가 나와. 목표는 편집 2~3시간을 10분으로 줄이는 거야.

== 만들 화면 ==

1. 첫 실행
   사진 접근 권한 요청, AI 연결(Claude / Codex 중 선택 후 로그인), 스튜디오 이름 입력.
   3단계를 순서대로. 건너뛸 수 있는 건 건너뛰게.

2. 갤러리 (첫 화면)
   들어온 촬영본 카드 그리드. 카드에 썸네일, 길이, 날짜, "결과물 3개" 배지.
   빈 상태: "아이폰으로 찍으면 여기 자동으로 들어와요"

3. 편집안 상세 (이 제품의 본체. 여기에 가장 공들여줘)
   3단 구조.
   왼쪽: 영상 미리보기 + 그 아래 장면 카드 목록
   오른쪽: AI 와의 채팅
   아래: 추천 칩 + 입력창
   장면 카드에는 썸네일, 자막 문구, 길이, 역할 배지(훅 / 시범 / 설명 / 마무리).
   카드에서 바로 "빼기", "늘리기", "자막 고치기" 가 돼야 해.
   타임라인 눈금자나 트랙은 절대 넣지 마. 카드 목록으로만 구조를 보여줘.

4. 결과물
   만들어진 영상 목록. 이전 버전과 나란히 비교, 내보내기 버튼.

5. 만드는 중
   진행률. 단계 표시("자막 만드는 중", "화면 잡는 중", "만드는 중").

6. 실패
   붉은 알림창이 아니라 채팅 안에 AI 말투 메시지로.
   예: "이 영상은 소리가 없어서 자막을 못 만들었어요"

7. 설정
   AI 연결 상태, 스튜디오 이름, 촬영본 보관 기간, 사진 폴더.

각 화면마다 빈 상태와 로딩 상태도 같이 그려줘.

== 문구 규칙 (제일 중요) ==

사용자가 못 알아듣는 단어가 하나라도 있으면 실패야. 전문 용어를 전부 바꿔.

  인코딩 → 만드는 중
  렌더 → 만들기
  컴포지션 → 편집안
  리프레임 / 크롭 → 화면 잡기
  트랜스크립트 → 자막
  프록시 → (노출하지 않음)
  타임라인 → (노출하지 않음)

추천 칩 예시: "숏폼 뽑아줘", "자막 넣어줘", "쉬는 구간 잘라줘", "인스타 규격으로"
타이핑 없이 칩만 눌러서도 주요 작업이 되게 해줘.

== 실제 콘텐츠 예시 (목업에 이 문구들을 써줘) ==

영상 제목: "골반이 틀어져있다면, 이 동작 안되실걸요?"
자막 문구: "양 쪽을 비교해봤을때,", "가능성이 높다는 겁니다", "다음 영상으로 해결해보세요"
채팅: 사용자 "쉬는 구간 빼고 인스타용으로 만들어줘"
      AI "쉬는 구간 2곳, 5초를 빼고 만들었습니다. 아래쪽 동작을 가리지 않게 자막을 위에 두었어요."

== macOS 네이티브 규칙 ==

웹앱처럼 보이면 안 돼.
왼쪽 사이드바 + 가운데 콘텐츠 + 오른쪽 패널 구조.
표준 macOS 컨트롤, 표준 여백, 시스템 폰트 관습을 따라줘.
그림자 쓰지 말고 1px 선으로 구분해.
창 크기는 1440x900 기준. 최소 1100x700 에서도 깨지지 않게.

== 절대 하지 말 것 ==

- 다크 모드 만들지 마. 라이트 하나만.
- iOS / 아이폰 화면 만들지 마. macOS 전용이야. 아이폰은 촬영만 해.
- 타임라인 편집기, 트랙, 키프레임, 눈금자 만들지 마.
- 영상 안에 들어가는 자막 스타일을 디자인하지 마.
  그건 크리에이터 실제 영상을 픽셀로 재서 이미 확정된 값이야(흰 글씨 + 검은 외곽선,
  화면 높이의 3.59%, 하단 23.5% 지점, 영문 보조자막은 노란색).
  앱 UI 디자인과 영상 자막 스타일은 완전히 별개니까 섞지 마.
  목업 안 미리보기에 자막을 보여줄 때는 위 값을 그대로 묘사만 해.
- 화려한 그라디언트, 일러스트, 이모지 장식 쓰지 마. 작업 도구야.

== 순서 ==

한 번에 다 만들지 말고 이 순서로 하고 매번 확인받아.

1) 갤러리
2) 편집안 상세 (가장 중요)
3) 결과물 + 만드는 중 + 실패
4) 첫 실행 + 설정

각 단계에서 왜 그렇게 배치했는지 한두 줄로 설명해줘.
