### 커스텀한 것 (이유)

| 값 | 어디 | 왜 |
|---|---|---|
| 강조색 `#2D6A55` | `Tokens.Palette.accent` | 시스템 강조색은 Mac 마다 다르다. 주요 버튼 색이 기기마다 달라지면 화면 설명이 안 맞는다. 시안이 쓰는 초록으로 고정 |

### 추측한 것 (근거가 시안뿐이거나 없음)

1. **묶음 기준** — 오늘 / 이번 주 / 지난주 / 그 전. 사진 앱을 따랐다.
   실제로 하루 몇 편씩 찍는지 모른다. 하루에 10편이면 "오늘" 이 너무 길어진다
2. **말소리 표시** — `잘 들려요 · 조금 시끄러워요 · 소리가 없어요` 세 단계.
   실제 판단 기준(무음 비율? SNR?)은 개발이 정한다. 화면은 세 단계만 안다
3. **칸에 보여주는 것** — 제목 2줄 + 시각 + 결과물 수.
   제목은 말소리에서 뽑는다고 가정했다. 말소리가 없는 촬영본은 제목이 빈다 —
   지금은 시각으로 대신 보여주게 뒀다
4. **길이 뱃지** — 사진 앱처럼 썸네일 오른쪽 아래. 3분짜리도 `2:56` 한 줄로 들어간다
5. **거르개 3칸** — `전체 · 편집 전 · 결과물 있음`. 시안 그대로다. "이거 이미 만들었나" 를
   푸는 장치라고 봤다

### 물어본 것과 답 (2026-09-25)

1. **설정을 사이드바에 넣을까?** → **넣지 않는다.** 앱 메뉴 `마디 > 설정…` (⌘,) 가 기본 경로다.
   사이드바 맨 아래 스튜디오 이름 줄에 톱니를 붙여 누를 수 있다는 것만 보인다
2. **`바로 숏폼 뽑기` 와 `편집안 열기` 를 둘 다 둘까?** → **하나로 합친다. `숏폼 만들기`.**
   누르면 편집안이 열리고 AI 가 초안을 짜기 시작한다. 실제 영상 만들기는 장면 카드를 본 뒤
   편집안 안에서 한다. **장면 카드를 건너뛰고 영상이 나오는 길은 없다** (`§1-3`, `§10`)
3. **촬영본 지우기** → "삭제" 라는 말을 쓰지 않는다. `목록에서 숨기기` 이고,
   누르면 상태줄이 "사진 앱의 원본은 그대로 있어요" 라고 말한다
4. **1100pt 에서 3칸?** → **4칸.** 세로 칸이라 3칸이면 한 화면에 4~5개밖에 안 보인다.
   칸 수를 직접 세고 `.flexible` 로 폭을 나눠 갖게 바꿨다 (`.adaptive` 는 1440 에서
   오른쪽에 빈 폭을 남겼다)

### 샘플 그림을 둘로 나눴다

촬영본 썸네일이 자막 박힌 완성본 프레임이었다. 원본에는 자막이 없다.
- 촬영본 → `docs/design/sample-frames/` (자막 아래끝 0.235 인 편만 골라 위 70% 만 남김)
- 결과물 → `reference/` (자막 있는 그대로)

미리보기에서 "원본" 과 "만든 것" 이 같아 보이면 안 된다. 3단계 재생 막대에서 특히 그렇다.
위 70% 만 쓰기 때문에 촬영본 썸네일은 실제보다 조금 당겨 보인다 — 공개본에서 자막을 지울
방법이 없어서 생긴 한계다.
