### 추측한 것 (근거가 시안뿐이거나 없음)

1. **묶음 기준** — 오늘 / 이번 주 / 지난주 / 그 전. 사진 앱을 따랐다.
   실제로 하루 몇 편씩 찍는지 모른다. 하루에 10편이면 "오늘" 이 너무 길어진다
2. **말소리 표시** — `잘 들려요 · 조금 시끄러워요 · 소리가 없어요` 세 단계.
   실제 판단 기준(무음 비율? SNR?)은 개발이 정한다. 화면은 세 단계만 안다
3. **칸에 보여주는 것** — 제목 2줄 + 시각 + 결과물 수.
   제목은 말소리에서 뽑는다고 가정했다. 말소리가 없는 촬영본은 제목이 빈다 —
   지금은 시각으로 대신 보여주게 뒀다
4. **길이 뱃지** — 사진 앱처럼 썸네일 오른쪽 아래. 3분짜리도 `2:56` 한 줄로 들어간다
5. **거르개 3칸** — `전체 · 편집 전 · 결과물 있음`. 시안 그대로다. "이거 이미 만들었나" 를
   푸는 장치라고 봤다

### 물어볼 것

1. **설정을 사이드바에 넣을까?**
   시안(`03-Results`)은 사이드바에 `스튜디오 > 설정` 칸이 있다. 지침은
   "설정은 macOS `Settings` 씬 + `Form`"(⌘,)이다. 둘을 같이 두면 같은 것이 두 군데가 된다.
   → 지금은 **사이드바 칸을 빼고**, 사이드바 맨 아래 스튜디오 이름을 누르면 설정이 열리게 했다.
   크리에이터가 ⌘, 를 모를 테니 누를 자리는 남겨야 한다고 봤다. 이대로 둘까?

2. **`바로 숏폼 뽑기` 가 갤러리에 있어야 하나?**
   시안에는 촬영본을 고르면 `바로 숏폼 뽑기` 와 `편집안 열기` 두 버튼이 있다.
   편집안을 열면 어차피 `숏폼 뽑아줘` 를 누르게 되는데, 갤러리에서 바로 만들면
   장면 카드를 못 보고 만들어진다 (`AGENTS.md §1-3` 장면 단위로 보여준다).
   → 지금은 시안대로 두 버튼 다 뒀다. 하나로 줄일지 물어본다

3. **촬영본을 지우는 것** — 우클릭에 `보관함에서 빼기` 만 뒀다.
   원본(iCloud 사진)은 건드리지 않는다는 뜻인데, 그러면 사람은 "지웠는데 왜 또 들어오지?" 를
   겪는다. 문구를 더 풀어 쓸지, 아예 빼기도 없앨지 물어본다

4. **1100×700 에서 한 줄에 3칸**이 맞나?
   칸을 더 작게 하면 4칸까지 들어가지만 제목이 3줄로 넘어간다. 지금은 3칸 + 제목 2줄이다
