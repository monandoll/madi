# 공개 숏폼 1편 실측 (2026-09-23)

촬영 원본이 아직 없어서, 크리에이터가 공개한 유튜브 숏츠로 자막 스타일만 먼저 쟀다.

- 출처: `youtube.com/shorts/EDpBGkaNJmU` (auto-dubbed 버전)
- 방법: 브라우저 canvas 로 10프레임 캡처, 720x1280
- 프레임: `spike/reference/public/`

**한계**: 1편만 쟀고 유튜브 720p 재인코딩본이다. §9 절차는 5편을 요구한다.
`reference/final.mp4`(인스타 원본)가 들어오면 다시 잰다. `tokens.MEASURED` 는 아직 `false`.

## 1. 측정값

| 항목 | 실측 (720x1280) | 1080x1920 환산 | 신뢰도 |
|---|---|---|---|
| 자막 하단 여백 비율 | 0.2344 ~ 0.2352 | 0.235 | **높음** — 4프레임에서 거의 안 흔들림 |
| 본문 글자 높이 | 47~49px (3.7%) | 71px | 높음 |
| 외곽선 두께 (바깥) | 4~5px | 6~7.5px | 중간 — 글자 간격과 섞임 |
| 보조 문구 비율 | 본문의 약 0.46 | — | 중간 |
| 한 줄 최대 글자 수 | 12자 | — | 높음 |

## 2. 판정

**자막 크기는 고정이다. fit-to-width 가 아니다.**
글자 수 9~12자에서 폭 비율은 0.61~0.82 로 변했는데 글자 높이는 47~49px 로 일정했다.
→ `Caption.tsx` 에 폭 기준 자동 스케일을 넣지 않는다.

**강조색을 쓰지 않는다.** 본문은 전부 흰색이었다. 기능은 남기되 기본으로 쓰지 않는다.

**보조 문구(영문)는 노란색이 맞다.** 다만 이 영상이 auto-dubbed 버전이라
인스타 원본에도 영문이 있는지는 확인 안 됐다.

## 3. 추정이 틀렸던 것

프로브 첫 렌더에서 자막 폭이 0.535 로 나오자 "원본은 85~90% 를 채우니 fontSize 를
92 → 150 근처로 키워야 한다"고 적었다. **반대였다.**

실측 글자 높이는 3.7% 인데 프로브는 4.74% 였다. 즉 프로브가 이미 **30% 더 컸다**.
폭이 좁아 보인 건 글자가 작아서가 아니라 원본 자막이 원래 화면을 꽉 채우지 않기 때문이다.
`fontSize` 는 92 → **72** 로 내렸다.

추측으로 150을 박았으면 전작이 노란 박스 56px 을 박아 놓고 "학습됐다"고 한 것과 같아졌다.
**재기 전에 값을 고치지 않는다**는 규칙이 실제로 작동한 사례다.

## 4. 품질 게이트 G4 를 고쳐야 한다

`AGENTS.md §8 G4` 는 "글자 높이 >= 프레임 높이 4.5%" 를 하드 게이트로 걸었다.
**크리에이터 실제 영상이 3.7% 로 이 게이트를 통과하지 못한다.**

내가 근거 없이 정한 숫자였다. 게이트를 데이터에 맞춰야지 반대가 아니다.
→ G4 를 3.2% 로 낮춘다 (실측 3.7% 에 여유 -15%).

## 5. 스키마 갭 — Composition 이 표현하지 못하는 것

13초 지점에 **상하 2분할 비교 화면**이 있었다.
같은 동작의 두 테이크를 위아래로 동시에 띄우고, 각 영역 왼쪽에 초록 O / 빨강 X 를 붙였다.

현재 `Scene` 은 `source: { videoId, in, out }` 단일 소스만 가진다.
**이 화면은 지금 스키마로 만들 수 없다.**

전작이 망한 이유가 정확히 이것(편집 어휘의 구조적 한계)이므로, 같은 실수를 반복하지 않으려면
`AGENTS.md §5` 에 아래가 들어가야 한다.

- `Scene.layout`: `'full' | 'splitV' | 'splitH' | 'grid'`
- `Scene.sources`: 단일 `source` 대신 배열. 레이아웃 슬롯마다 하나씩
- `Overlay.kind` 에 `'mark'` 추가 (payload: `{ symbol: 'o' | 'x' | 'check' }`)
- `Overlay.anchor` 를 레이아웃 슬롯 기준으로도 찍을 수 있게 (`slot: number`)

0단계 스파이크에서 이 프레임을 재현해 보고 확정한다. **재현 안 되면 0단계 통과가 아니다.**
