# 리프레임 크롭 중심 규칙 — 실측 (2026-09-25)

1단계 시작. 0단계가 넘긴 두 항목을 **먼저 재고** 규칙을 정한다.

- 가로로 넓은 자세 (9:16 에 안 들어감)
- 2인 영상의 피사체 선택

대상: 대용 원본 6편 (`spike/source/raw/`, 커밋 안 함).
도구: `madi-spike subjects` · `madi-spike croptest`.

## 1. 먼저 — 가로로 안 들어가는 건 예외가 아니라 기본이다

`madi-spike subjects`. 1등 덩어리의 폭이 9:16 크롭 가용 폭을 넘는 프레임 수:

| 영상 | 내용 | 폭 초과 |
|---|---|---|
| `uw1aUHnMfo8` | 서 있는 전신 | **1/7** |
| `VtFNkL7oAWM` | 앉은 자세 | **0/7** |
| `zV4hh3M5eGI` | 매트 바닥 (네발기기 · 플랭크) | **7/7** |
| `fuTjB-F6-DE` | 매트 엎드림 | 대부분 |
| `6U6Qp35FQaM` | 도수치료 2인 클로즈업 | **7/7** (마스크가 화면 전체) |

**바닥 자세는 전부 안 들어간다.** 서거나 앉은 자세는 거의 들어간다.
"가로로 넓은 자세" 는 드문 예외가 아니라 **바닥 운동의 기본 상태**다.

## 2. 크롭 중심 — 무게중심이 이긴다

후보 세 개를 재고 **크롭 안에 남는 마스크 비율**(= 몸이 덜 잘린 정도)로 비교했다.
높을수록 좋다.

| 영상 | 상자중심 | **무게중심** | 화면중앙 |
|---|---|---|---|
| `uw1aUHnMfo8` (서 있는 전신) | 0.880 | **0.994** | 0.978 |
| `zV4hh3M5eGI` (매트 바닥) | 0.587 | **0.684** | 0.642 |
| `VtFNkL7oAWM` (앉은 · 2분할) | 0.621 | **0.621** | 0.570 |
| `fuTjB-F6-DE` (매트 엎드림) | 0.521 | **0.527** | 0.524 |
| `6U6Qp35FQaM` (2인 클로즈업) | 0.368 | **0.379** | 0.364 |
| `NOCXAZE8XdQ` (세로 원본) | 1.000 | 1.000 | 1.000 |

**무게중심이 6편 전부에서 최고이거나 동률이다.**

상자중심이 `uw1aUHnMfo8` 에서 0.880 으로 떨어지는 이유가 이 선택의 근거다 —
팔을 벌리면 **상자가 팔 끝에 끌려가고 몸통이 크롭 가장자리로 밀린다.**
무게중심은 픽셀이 많은 몸통을 따라간다.

화면중앙도 나쁘지 않은데, 그건 이 6편이 전부 고정 카메라에 인물이 가운데 있어서다.
촬영 원본도 그럴 가능성이 크지만 **인물이 옆으로 움직이면 바로 깨진다.**

### 줌아웃하지 않는다

가로로 넘칠 때 다 담으려면 줌아웃해야 하는데, `zV4hh3M5eGI` 기준으로
인물 높이가 0.65 → **0.29** 가 된다. `G1`(0.55) 을 크게 밑돈다.
**G1 우선** 원칙대로 자른다 (`AGENTS.md §8`).

⚠ 다만 매트 바닥 자세는 몸의 **47% 가 잘린다.**
이건 **대용 원본이 16:9 라서 생기는 문제**다. 촬영 규칙(`docs/shooting.md`)은 세로 촬영을
요구하고, 세로 원본(`NOCXAZE8XdQ`)에서는 잘림이 **0** 이다 (1.000).
촬영 원본이 들어오면 다시 잰다.

→ 잘린 비율을 `Output.reviewReport` 에 남긴다. 조용히 자르지 않는다.

## 3. 2인 영상 — **별도 규칙이 필요 없다**

`6U6Qp35FQaM` (도수치료: 시술자 + 회원)에서 마스크 덩어리를 세 봤다.

**7프레임 중 6프레임이 덩어리 1개다.** 시술자와 회원이 붙어 있어 하나로 잡힌다.
마스크가 화면의 65~93% 를 덮는다.

즉 "누구를 피사체로 볼지" 를 **컴포넌트 분리로는 물을 수조차 없다.**

덩어리가 실제로 둘인 건 `VtFNkL7oAWM` 인데, 그건 2인이 아니라 **화면 2분할**
(같은 사람의 두 각도)이었다. 5/7 프레임에서 2개, 크기도 비슷했다(0.09 vs 0.055).

무게중심은 이 두 경우를 **자동으로** 처리한다:

- 붙어 있는 2인 → 사람이 많은 쪽으로 중심이 간다
- 2분할 화면 → 둘 사이를 잡는다 (상자중심과 같은 점수 0.621)

→ **"가장 큰 덩어리를 고른다" 같은 규칙을 넣지 않는다.**
  넣으면 2분할 화면에서 한쪽만 따라가 깨진다. 무게중심 하나로 충분하다.

## 4. 정한 것

1. **크롭 가로 중심 = 마스크 픽셀 무게중심** (상자중심 아님)
2. **가로로 넘치면 줌아웃하지 않고 자른다** (G1 우선). 잘린 비율을 리포트에 남긴다
3. **덩어리를 세지 않는다.** 2인이든 2분할이든 무게중심 하나로 처리한다
4. 세로 원본은 크롭이 전체 프레임이 되어 **자동으로 통과**한다 (1.000). 따로 분기하지 않는다

## 5. 아직 안 정한 것

- **세로 중심.** 이 6편은 전부 전체 높이를 쓰는 크롭이라 세로는 고를 게 없었다.
  원본이 9:16 보다 **세로로 길면**(예: 4:5 촬영) 세로도 골라야 한다
- **시간축 스무딩.** `G3`(인접 키프레임 중심 이동 <= 폭의 3%/frame) 를 아직 안 쟀다
- **줌(스케일) 키프레임.** 지금은 전체 높이 고정이다. 인물이 작게 찍힌 원본에서는
  확대해야 `targetSubjectHeightRatio` 에 닿는다
