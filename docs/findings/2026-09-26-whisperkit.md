# WhisperKit 채택 — 그리고 전사로 `pauseSec` · `maxDurationSec` 실측 (2026-09-26)

G6(자막 싱크)을 실제로 돌려 보려면 **낱말 단위 타임스탬프**가 필요하다.
전사만 2단계로 당겨 붙였다. 다이제스트 나머지와 Intel 폴백은 3단계 그대로다.

---

## 1. 붙인 것

- `WhisperKit` **0.9.4** (`minorVersion: 0.9.0` 으로 고정)
- `TranscriptionProvider` 프로토콜 + `WhisperKitProvider`
- 낱말 시각은 `DecodingOptions(wordTimestamps: true)` 로 켠다.
  **안 켜면 문장 단위만 오고 분절도 G6 도 불가능하다**

### 확인한 라이선스 (`AGENTS.md §13`: "모델 가중치 라이선스는 채택 시점에 확인한다")

- WhisperKit — MIT
- 모델 가중치 — OpenAI Whisper 를 CoreML 로 변환한 것. 원본이 MIT

### ⚠ `§2` 와 부딪히는 점 — 모델 다운로드

`§2` 는 "Apple Silicon 에서는 외부 바이너리를 받지 않는다. **첫 실행 준비 화면도 필요 없다**"
고 적고 있다. 가중치는 바이너리가 아니지만 **첫 실행 다운로드인 것은 같다**
(`base` 기준 수백 MB).

선택지는 둘이다. **사람이 정할 문제라 지금 정하지 않았다.**

| 안 | 대가 |
|---|---|
| 번들에 넣는다 | `.dmg` 가 그만큼 커진다 |
| 첫 실행에 받는다 | `§2` 가 없다고 한 준비 화면이 생긴다 |

## 2. Universal 빌드가 깨진다 — 3단계로 넘긴다

`ARCHS = arm64 x86_64` 로 한 번에 빌드하면 **WhisperKit 이 arm64 모듈만 내놓는다.**

```
error: could not find module 'WhisperKit' for target 'x86_64-apple-macos';
       found: arm64-apple-macos
```

- 아키텍처를 하나씩 지정하면(`ARCHS=arm64` / `ARCHS=x86_64`) **각각은 빌드된다.**
  Universal 한 번에 갈 때만 x86_64 슬라이스가 안 만들어진다
- 명시적 모듈을 꺼도(`SWIFT_ENABLE_EXPLICIT_MODULES=NO`) 같다

**§17 이 이미 답을 적어 뒀다** — Tier 2(Intel)는 WhisperKit 이 아니라 whisper.cpp 를 쓴다.
즉 x86_64 슬라이스에는 WhisperKit 이 **들어가면 안 된다.**
SPM 은 패키지를 아키텍처별로 빼지 못하므로, 제대로 된 해법은
3단계에서 `TranscriptionProvider` 를 아키텍처별로 가르는 것이다.

지금 한 것: **Debug 만 현재 아키텍처로 빌드**(`ONLY_ACTIVE_ARCH: YES`).
Release · Universal 은 **미해결로 남겨 둔다.** 숨기지 않는다.

### 곁가지 — 0.18 은 Vapor 를 끌고 온다

처음에 `from: 0.9.0` 으로 적었더니 **0.18.0** 이 잡혔고,
의존성에 **Vapor(웹 서버)** · `swift-openapi` 가 딸려 왔다.
`§16` 이 "웹 UI · HTTP 서버" 를 하지 않기로 했는데 의존성 그래프에 서버 프레임워크가
들어오는 건 맞지 않는다. `minorVersion: 0.9.0` 으로 고정해 0.9.4 를 쓴다
(의존성은 `swift-transformers` · `swift-argument-parser` 뿐).

## 3. ★ 전사 + OCR 을 맞춰 두 값을 실측했다

추측으로 두었던 `pauseSec` · `maxDurationSec` 을 **잴 수 있게 됐다.**

방법 (`madi-spike capsync`):
1. WhisperKit 으로 낱말 시각을 얻는다
2. 같은 영상의 번인 자막을 OCR 해 덩어리 경계를 얻는다
3. 두 개를 맞춰 **"끊은 자리의 쉼"** 과 **"덩어리 안에서 안 끊은 쉼"** 을 따로 센다

공개본 6편 · 118덩어리 · 331낱말:

| 영상 | 끊은 자리 쉼 (중앙/p90/최대) | 안 끊은 쉼 (중앙/p90/최대) | 덩어리 길이 (중앙/최대) |
|---|---|---|---|
| `8DF9jrxQM4U` | 0.400 / 0.540 / 0.720 | 0.000 / 0.120 / 0.600 | 1.250 / 1.750 |
| `EDpBGkaNJmU` | 0.440 / 0.800 / 2.260 | 0.000 / 0.060 / 0.220 | 1.000 / 1.500 |
| `59HP4jxLFeA` | 0.440 / 0.620 / 1.000 | 0.000 / 0.000 / 0.460 | 0.750 / 2.750 |
| `L469kzZZe1E` | 0.360 / 0.600 / 0.680 | 0.000 / 0.000 / 0.340 | 1.000 / 2.000 |
| `UzemW44yzSo` | 0.260 / 0.600 / 0.720 | 0.000 / 0.000 / 0.360 | 1.000 / 1.500 |
| `RnP7b0JFWj4` | 0.400 / 0.620 / 0.780 | 0.000 / 0.000 / 0.280 | 0.750 / 1.500 |

**두 분포가 깨끗하게 갈린다.** 안 끊은 쉼은 6편 전부 중앙값이 **0.000** 이고,
끊은 자리는 0.26~0.44 다.

### `pauseSec` = **0.30** (추측 0.35 → 실측)

안 끊은 쉼의 p90(0.00~0.12)보다 넉넉히 위이고,
끊은 자리 중앙값(6편 중 5편이 0.36~0.44)보다 아래다.
`UzemW44yzSo` 만 중앙 0.26 으로 기준 아래인데, 분절은 글자 수 조건으로도 끊으므로
쉼을 놓쳐도 덩어리가 무한정 길어지지 않는다.

### `maxDurationSec` = **3.0** (추측 2.5 → 실측)

**추측 2.5 였으면 크리에이터 자막 하나가 걸렸다.** `59HP4jxLFeA` 에 2.75초짜리가 있다.
실측 최댓값 위로 올린다. G4·G5·G2·G7 에 이어 **다섯 번째로 추측값이 실측에 깨진 사례**다.

### `targetDurationSec` = 1.0 (확인)

6편 전부 중앙값이 0.75~1.25초다. 그대로 둔다.

## 4. 측정의 한계

- OCR 경계가 ±0.25초(초당 4프레임) 흔들린다. 맞출 때 그만큼 여유를 줬으므로
  **쉼 값도 ±0.25초 안에서 봐야 한다.** 0.30 과 0.35 를 가르는 정밀도는 없다 —
  가른 것은 **"0.0 근처" 와 "0.4 근처"** 다
- 전사 오독이 있다 ("4자 다리" → "기억자 다리"). 낱말 **시각**에는 영향이 적다
- 6편이다. `§0-7` 의 "5편 이상" 은 넘지만 10편은 아니다
- `EDpBGkaNJmU` 의 끊은 자리 최대 2.26초는 자막이 없는 구간(침묵)을 사이에 둔 경계다.
  쉼 자체가 아니라 **말이 없던 구간**이다
