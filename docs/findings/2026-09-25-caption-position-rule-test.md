# 자막 위치 규칙 가설 검증 — **기각** (2026-09-25)

`docs/findings/2026-09-25-caption-position-10.md` 에서 자막 위치가 세 무리로 갈리는 걸 재고,
"**자막이 피사체를 피해 올라간다**" 는 가설을 세웠다.
사람 분할 마스크로 C 무리에서도 사람이 잡히게 됐으므로 가설을 검증했다.

## 검증한 규칙

> 측정된 위치 3개 중 **피사체 마스크와 안 겹치는 가장 낮은 것**을 고른다.
> A 0.235 → B 0.300 → C 0.475 순으로 내려가며 본다.

"겹친다" 는 **자막 띠 안의 피사체 가로 점유율**로 잰다.
마스크 **상자**로는 못 잰다 — 인물 상자가 화면의 87% 를 차지해서 어느 위치든 겹친다고 나온다.
도구: `madi-spike captionband` (편당 4프레임 평균).

### 어떤 임계값으로도 안 된다

규칙이 맞으려면 임계값 `T` 가 동시에 이래야 한다:

- A 무리가 A 를 고르려면 → `T > max(0.408, 0.568, 0.425)` = **T > 0.568**
- C 무리가 A 를 건너뛰려면 → `T ≤ min(0.288, 0.296, 0.571, 0.699)` = **T ≤ 0.288**

**동시에 만족할 수 없다.** 규칙 자체가 성립하지 않는다.

"가장 비어 있는 곳을 고른다"(임계값 없이 argmin)로 느슨하게 바꿔도 **5/10** 이다.
3개 중 무작위로 고르면 33%, 5/10 은 50% — **우연과 구분되지 않는다.**

## 왜 틀렸나 — 반대 방향이었다

`frames/2026-09-25-caption-band-hypothesis-fails.jpg`
(하늘색 = A 0.235 · 노랑 = B 0.300 · 빨강 = C 0.475 · 흰 선 = 실제 자막 위치)

세 프레임 모두에서 **실제 자막이 피사체 위에 얹혀 있다.**
`RnP7b0JFWj4` 와 `UzemW44yzSo` 는 가장 비어 있는 A 자리(바닥 · 빈 공간)를 두고도
인물 위를 골랐다.

즉 크리에이터는 자막을 피사체를 **피해서** 두는 게 아니라, 그 순간 **설명하는 부위 근처**에 둔다.
1번 프레임은 무릎 얘기를 하면서 자막이 무릎에, 3번도 무릎에 있다.

**이건 기하가 아니라 내용이다.** 마스크로는 예측할 수 없다.

## 그래서 무엇을 하나 — 슬롯을 늘린다 (제안)

위치를 스타일에 하나로 박을 수도 없고(편마다 다르다),
AI 에게 좌표를 정하게 할 수도 없다(`AGENTS.md §1-2`).

남는 길은 `§0-4` 가 이미 말한 것이다 — **AI 는 슬롯만 채운다.**

```swift
Caption.Slot:  .main   // 0.235  아래. 말하는 상반신 장면
               .mid    // 0.300  중간. 서 있는 전신
               .high   // 0.475  위.  바닥·하체 클로즈업
```

- **좌표는 스타일(`short.v1.json`)이 갖는다.** AI 는 `.main | .mid | .high` 중 하나를 고른다
- 슬롯 이름은 **내용어**여야 한다(무엇을 설명하는 장면인가). 좌표를 암시하면 안 된다
- 세 값은 실측에서 나왔다 (10편, 편 안에서는 거의 완벽히 고정)

⚠ **넣지 않았다.** 규칙이 맞으면 넣기로 했는데 맞지 않았고,
슬롯을 늘리는 건 `Caption` 스키마 변경이라 사람이 정할 일이다.

## 이 검증이 실제로 막은 것

가설을 믿고 `short.v1.json` 에 위치 3개 + "피해서 고르기" 규칙을 넣었다면,
리프레이밍을 만든 뒤에야 자막이 엉뚱한 데 붙는 걸 발견했을 것이다.
그때는 원인이 리프레이밍인지 자막 규칙인지 구분하기 어려웠을 것이다.

**규칙을 넣기 전에 10편으로 검증한다** 를 `§9` 절차에 추가할 만하다.
