# 롱폼 (6단계)

2분 이상 영상에서 **챕터 나누기**와 **숏폼 자동 추출**. AI 없이도 버튼으로 되고, AI 는 같은 것을 `get_chapters` 도구로 본다.

## 챕터 (`apps/engine/src/chapters/split.ts`, 순수 함수)

입력: 자막 문장, 무음 구간, 장면 전환 시각, 길이.

1. 경계 후보 = 문장 사이 쉼(0.6초 이상). 점수 = 쉼 길이(최대 4) + 장면 전환이 ±6초 안이면 +2 + 무음 1.5초 이상이면 +1. 자막이 없으면 장면 전환마다 후보(점수 3).
2. 앞에서부터: 길이 < 45초면 안 자름 · 점수 ≥ 3(강한 경계)이면 자름 · 180초 넘었고 점수 ≥ 1.5 면 자름 · 420초 넘으면 target 넘긴 뒤 가장 좋은 곳(같으면 뒤쪽)에서 자름. 마지막 조각이 45초 미만이면 앞에 붙임.
3. 제목 = 챕터 첫 문장 24자 (자막 없으면 "1부, 2부…").
4. 하이라이트 = 챕터가 60초 이하면 통째로, 아니면 문장 경계에 맞춘 40초 창 중 말이 가장 많은 것(자막 없으면 앞 40초). 15초 미만이면 없음.

`chapters` 잡(`workers/chapters.ts`): 자막이 없고 소리가 있으면 먼저 자막을 만들고(기다림), 무음(배운 기준, 최소 1초)·장면을 훑어 나눈 뒤 `chapters` 테이블에 저장. 메시지 kind `chapters` 카드가 붙는다.

`then='shorts'` 면 하이라이트가 있는 챕터에서 순서대로 max 개 → `Edit(keep, vertical, subtitles)` → 렌더 잡. 카드는 렌더 워커가 붙인다. 렌더는 여전히 `Edit` 로부터.

## 화면

- 영상 상세(AI 꺼짐): 버튼 4개 + `챕터 나누기` `숏폼 3개 뽑기` (2분 이상일 때).
- 영상 상세(AI 켜짐): 칩이 `챕터 나눠줘` `숏폼 3개 뽑아줘` `자막 넣어줘` 로 바뀐다.
- 챕터 카드: 번호 · 제목 · 구간 · `숏폼으로` (하이라이트 구간으로 수동 숏폼과 같은 액션).

## API

- `POST /api/videos/:id/actions { type: 'chapters' }` / `{ type: 'auto_shorts', max }` — 30초 미만이면 409 `too_short_for_chapters`
- `GET /api/videos/:id` → `chapters`
- MCP `get_chapters { refresh? }` — 없으면 만들고 기다린다. 에이전트는 이걸 보고 `extract_shorts` 로 뽑는다.
