마디

운동·재활 영상을 말로 편집하는 도구예요. 설치하면 영상 폴더가 갤러리로 뜨고, 자막·쉬는 구간 잘라내기·세로 변환·숏폼이 바로 됩니다.

확인 중… 최신 버전 찾는 중…
받은 파일을 열면 설치가 끝나고 브라우저가 열려요.
  1. 받은 madi-engine-….exe 를 열어요.
  2. 파란 경고가 뜨면 추가 정보 → 실행. (아직 서명이 없어서 그래요)
  3. 설치는 알아서 끝나고 브라우저가 열려요. 스튜디오 이름과 영상 폴더만 고르면 됩니다.
  1. 받은 madi-engine-….pkg 를 열고 계속 → 설치. 맥 비밀번호를 물어요.
  2. "확인할 수 없어 열 수 없다"고 하면 시스템 설정 → 개인정보 보호 및 보안 맨 아래 그래도 열기. (아직 서명이 없어서 그래요)
  3. 설치가 끝나면 브라우저가 열려요. 스튜디오 이름과 영상 폴더만 고르면 됩니다.

이 페이지를 PC 에서 열어주세요

마디는 영상이 있는 PC(Windows 또는 Mac)에 설치해요. 설치가 끝나면 폰에서도 그 PC 를 볼 수 있어요.

다른 파일이 필요하면

Windows 10/11 .exe Mac (Apple Silicon · M1 이후) .pkg Mac (Intel) .pkg

내 맥이 어느 쪽인지 모르면: 왼쪽 위 사과 메뉴 → 이 Mac에 관하여. "칩 Apple M…" 이면 Apple Silicon.

설치 뒤

  1. 트레이(작업 표시줄 오른쪽 / 메뉴 막대)에 점 아이콘이 생겨요. 브라우저가 닫혔으면 눌러서 마디 열기.
  2. 업데이트는 자동으로 받아요. 새 버전은 다음에 켤 때 적용돼요.
  3. 폰이나 다른 PC 에서 보려면 설정 → 밖에서 접속하기. 같은 와이파이면 http://PC주소:41520 으로 바로 돼요.
